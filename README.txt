VIGÍA C-UAS V5 — PAQUETE WEB MÓVIL

Incluye cámara en vivo, captura de fotografía, solicitud de ubicación, enlace a OpenStreetMap, registro manual e historial local.

IMPORTANTE:
- Para que la cámara y la ubicación funcionen, la aplicación debe abrirse desde una dirección HTTPS.
- Este paquete aún NO detecta drones automáticamente. Registra observaciones manuales y fotos.
- Las evidencias se guardan en el almacenamiento local del navegador. No borres los datos del sitio si quieres conservarlas.
- No se envían datos a un servidor.
- La ubicación se obtiene solo al pulsar el botón correspondiente.

INSTALACIÓN DESDE ANDROID SIN PC:
1. Descarga y descomprime este ZIP en tu teléfono.
2. Publica los archivos en un alojamiento HTTPS gratuito, por ejemplo GitHub Pages, usando el navegador del teléfono.
3. Abre la dirección HTTPS publicada en Chrome.
4. Menú ⋮ > Añadir a pantalla principal o Instalar aplicación.
5. Concede permisos de cámara y ubicación cuando los solicite.

La publicación en GitHub Pages requiere una cuenta GitHub gratuita y subir los archivos del paquete. El alojamiento puede cambiar sus condiciones; verifica las opciones disponibles al crear el sitio.
